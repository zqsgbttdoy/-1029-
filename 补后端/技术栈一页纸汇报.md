# 监理现场管理系统 · 技术架构一页纸

> 汇报用途 ｜ 版本信息均取自项目实际配置文件（`pom.xml` / `application.yml`）实测识别

---

## 技术栈总览

| 层次 | 技术选型 | 版本 | 通俗说明 |
|------|---------|------|---------|
| **前端** | 原生 HTML / CSS / JavaScript | 无框架 | 网页界面浏览器直接运行，简单可靠 |
| **后端** | Java + Spring Boot | Java 17 / Spring Boot 3.2.5 | 系统"大脑"，处理全部业务逻辑 |
| **数据库** | MySQL | 8.0 | 存放业务数据的"电子仓库" |
| **服务器** | Nginx + 阿里云 ECS | Nginx ≥1.20 / Ubuntu 22.04 | 对外访问入口与请求转发 |
| **移动端** | 微信小程序 | — | 现场人员手机扫码即用 |

**架构定性**：前后端分离的 Web 应用，单机全栈部署（后端+数据库+Nginx+前端同处一台服务器），配套微信小程序。

---

## 核心三问答复

- **前端**：原生 HTML/CSS/JavaScript，**未使用 React / Vue / Angular 等框架**。26 个页面 + 自研统一基座 `app.js`（登录、请求、安全、提示）。
- **后端**：**Java 17 + Spring Boot 3.2.5**，经典四层架构，RESTful API（前缀 `/api`，端口 8080）。
- **数据库**：**MySQL 8.0**（连接池 Druid 1.2.22，字符集 utf8mb4，核心 21 张表）。

---

## 安全与质量保障（领导关注）

✅ BCrypt 密码加密存储　✅ JWT 身份认证　✅ HTTPS 强制加密传输
✅ 登录防暴力破解　✅ XSS/文件上传防护　✅ 生产密钥环境变量隔离

---

## 一句话总结

> 采用**业界主流成熟的 Java Spring Boot + MySQL 后端 + 轻量纯静态前端**，配套微信小程序，单机部署即可稳定支撑监理业务。选型以"稳定、易维护、低运维成本"为核心，适合单位内部长期使用。
