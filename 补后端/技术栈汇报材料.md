> 用途：向团队 / 领导汇报项目整体技术架构

## 一、技术栈总览（一页看懂）

| 层次 | 采用的技术 | 具体版本 | 一句话通俗说明 |
|------|-----------|---------|--------------|
| **前端** | 原生 HTML5 + CSS3 + JavaScript | 无框架、无构建工具 | 网页界面直接由浏览器运行，简单可靠、加载快 |
| **后端** | Java + Spring Boot | Java 17 / Spring Boot 3.2.5 | 系统的"大脑"，处理所有业务逻辑和数据运算 |
| **数据库** | MySQL | 8.0.x | 存放所有业务数据的"电子仓库" |
| **服务器/部署** | Nginx + 阿里云 ECS | Nginx ≥1.20 / Ubuntu 22.04 | 负责对外访问入口与请求转发 |
| **移动端** | 微信小程序 | — | 现场人员手机扫码即可使用 |

**整体架构定性**：前后端分离的 **Web 应用系统**，单机全栈部署（后端、数据库、Nginx、前端页面同处一台服务器），并配套微信小程序生态。

## 二、三个核心问题的明确答复

### 问题 1：前端技术

**答复：原生 HTML / CSS / JavaScript，没有使用任何前端框架（非 React、非 Vue、非 Angular）。**

- 前端由 **26 个独立 `.html` 页面** 组成，样式和脚本直接内联在页面中
- 采用 **ES5 风格** 的原生 JavaScript（`var` 声明、传统函数），无需编译构建
- 通过一个自研的**统一基座脚本** `assets/app.js` 封装公共能力：
  - 登录态管理（`getToken` / `requireAuth` / `logout`）
  - 统一 API 请求封装（`apiFetch` / `apiGetPage`，自动携带身份令牌、401 自动跳登录、错误统一提示）
  - 安全防护（`escape` 转义，防 XSS 攻击）
  - UI 组件（`toast` 消息提示、顶栏初始化）
- 另配套一套 **微信小程序**（`miniprogram/` 目录），复用相同的后端 API

**为什么这样选型（可用于汇报解释）**：监理系统面向小用户量（50~300 人）内部使用，纯静态前端**上手快、部署简单、无需 Node.js 构建链、服务器零额外依赖**，运维成本最低，符合"够用、稳定、易维护"的定位。

### 问题 2：后端技术

**答复：Java 语言 + Spring Boot 框架。**

- 编程语言：**Java 17**（`pom.xml` 中 `<java.version>17</java.version>`）
- 应用框架：**Spring Boot 3.2.5**（继承 `spring-boot-starter-parent:3.2.5`）
- 架构分层：经典四层 —— `Controller`（接口层）→ `Service`（业务层）→ `Repository`（数据访问层）→ `Entity`（数据实体）
- API 风格：**RESTful**，接口统一前缀 `/api`，服务端口 8080

### 问题 3：数据库技术

**答复：MySQL 8.0 关系型数据库。**

- 数据库系统：**MySQL 8.0**（阿里云 ECS 自建）
- 连接驱动：`com.mysql:mysql-connector-j`
- 连接池：**Alibaba Druid 1.2.22**（负责高效管理数据库连接）
- 字符集：`utf8mb4` / `utf8mb4_unicode_ci`（完整支持中文与特殊字符）
- 表结构：核心 21 张表，涵盖用户、部门、项目、监理日记/日志、安全日志、通知单、联系单、会议纪要、月报、消息等业务
- 补充说明：项目另集成 **H2 内存数据库**，仅用于本地演示/自动化测试，**生产环境不启用**

## 四、安全与质量保障要点（领导关注点）

- ✅ **密码加密存储**：采用 BCrypt 强单向加密，数据库不保存明文密码
- ✅ **身份认证**：JWT 令牌机制，登录过期自动跳转，防越权访问
- ✅ **传输加密**：生产环境 Nginx 强制 HTTPS 加密传输
- ✅ **防攻击**：登录接口频率限制（防暴力破解）、XSS 转义防护、文件上传白名单校验
- ✅ **配置隔离**：开发/生产双配置文件，生产密钥通过环境变量注入，杜绝硬编码泄露
- ✅ **数据防护**：所有列表接口分页上限钳制，防恶意超大查询拖垮数据库

## 五、部署架构说明

```
用户浏览器 / 微信小程序
        │
        ▼
   ┌─────────────┐   HTTPS(443)
   │   Nginx     │──────────────────┐
   │ (反向代理)  │                  ▼
   └─────────────┘         ┌──────────────────┐
        │ 静态页面          │  Spring Boot jar  │
        ▼                  │   (Java 17:8080)  │
   前端 26 个 HTML 页面      └──────────────────┘
   (/opt/supervision/static)         │
                                     ▼
                            ┌───────────────┐
                            │  MySQL 8.0     │
                            │  (3306 内网)   │
                            └───────────────┘
```

- **单机全栈部署**：Nginx、Spring Boot、MySQL、前端静态页面全部运行在同一台阿里云服务器上，无需 Redis、消息队列、Docker 等额外中间件
- **服务器规格建议**：50~300 人规模推荐 4 核 8G；软件环境锁定 Ubuntu 22.04 LTS + JDK 17 + MySQL 8.0 + Nginx ≥1.20
- **微信小程序前置条件**：需一个已完成 ICP 备案的国内 HTTPS 域名（备案周期约 1~3 周，是最耗时的准备项，须尽早启动）

## 六、汇报用一句话总结

> 本系统采用**业界主流且成熟的 Java Spring Boot + MySQL 后端 + 轻量纯静态前端**技术栈，配套微信小程序，单机部署即可稳定支撑监理现场管理业务。技术选型以"稳定、易维护、低运维成本"为核心原则，非常适合作为单位内部长期使用的小规模业务系统。
